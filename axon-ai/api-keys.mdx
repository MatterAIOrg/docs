API keys are used to authenticate requests to the MatterAI inference API. You can manage your API keys in the MatterAI console.

## Generate a new API key

<Steps>
<Step title="Generate a new API key">
Go to the [MatterAI API Key Management](https://app.matterai.so/api-keys) and click `Create Key` button.

<Frame>
  <img src="/images/axon/api-keys.png" alt="MatterAI API Key Management" />
</Frame>

</Step>
<Step title="Enter a name for the API key">
Enter a name for the API key.

<Frame>
<img src="/images/axon/create-api-key.png" alt="MatterAI API Key Management" />
</Frame>
</Step>
<Step title="Click on the Copy Key button">
Click on the `Copy Key` button to copy the API key.

<Frame>
<img src="/images/axon/copy-api-key.png" alt="MatterAI API Key Management" />
</Frame>
</Step>
</Steps>
